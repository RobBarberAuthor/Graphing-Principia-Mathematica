This is a repository for the svgs (plain and Inkscape) as well as some pngs of my graphs of Principia Mathematica's theorems and demonstrations. The graphs are made using the principles of a framework I call Conceptual Geometry which is first explored in my book The Philosopher's Map. I plan to graph all of PM.
It might be a while before I add some of the stuff, so, if you're viewing this now and there's only the Praeclarum Theorema graph stuff under 'justification tables' it's because I had to redo a bunch of stuff when I switched from Paint3D over to Inkscape. I have the original *2.x series on imgur though if you're interested.
